Markdown 简易使用说明
Markdown 是一种轻量级标记语言，让你能用纯文本格式编写文档，并轻松转换为结构化的 HTML。它的核心思想是“易写易读”，让你可以专注于内容本身，而不是复杂的排版。

在你的学习笔记场景中
结合你之前的学习需求，你可以这样利用 Markdown：

记录学习笔记：用 # 和 ## 组织章节，用 - 和 1. 列出要点，用 ```c++ 包裹代码片段。

插入截图和笔记：使用 ![图片描述](./MarkdownImage/图片名.png) 将你截取的 PPT 图片插入笔记中。

创建学习清单：用 - [ ] 和 - [x] 跟踪你的学习进度，如“- [x] 完成 C++ 复习”、“- [ ] 学习 Redis 高可用”。

💡 一些有用的写法示例
换行：在行末敲两个空格再按回车，或者用一个空行来开始新段落。

分隔线：用三个或以上的 --- 或 *** 单独成行，可以创建一条水平分割线。

转义字符：如果你需要显示原本有特殊含义的符号（如 *、#），可以在前面加反斜杠 \，例如 \*。

折叠内容：适合将冗长的代码或详细说明收起来，让笔记更干净：

html
<details>
<summary>点击展开详细内容</summary>
这里是折叠起来的文本或代码。
```cpp
cout << "Hello" << endl;
</details> ```
